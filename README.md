# AltQLauncher

一个轻量的 Windows 软件启动面板，使用 AutoHotkey v2 编写。

按住 **Alt**，按 **Q** 打开面板；继续点按 Q 切换分类。**松开 Alt 只关闭面板，不会启动软件**。只有点击图标或按 Enter 才启动选中的软件。

## 下载和安装

发布文件：

| 文件 | 用途 |
| --- | --- |
| `AltQLauncher-1.0.0-Setup-x64.exe` | Windows 10/11 64 位安装版，无需另装 AutoHotkey |
| `AltQLauncher-1.0.0-Portable-x64.zip` | 便携版，完整解压后双击 `AltQLauncher.exe` |
| `AltQLauncher-1.0.0-Source.zip` | 源码和 GitHub 工程 |
| `SHA256SUMS.txt` | 文件校验值 |

安装版默认只安装到当前用户的 `%LOCALAPPDATA%\Programs\AltQLauncher`，不要求管理员权限。安装时可选桌面快捷方式；完成后可运行程序并打开设置。也可从开始菜单找到主程序、设置和卸载入口。

升级前请先从托盘退出旧版。安装版不覆盖已有个人配置，卸载时也保留个人配置。不会默认设置开机启动。

便携版需要保留程序旁边的 `portable.flag`，该文件决定配置保存到本地目录。请使用可写目录。

当前发行文件未进行商业代码签名。可对照校验文件检查下载完整性；不要通过关闭系统防护来处理拦截问题。

## 使用

| 操作 | 行为 |
| --- | --- |
| 按住 Alt，再按 Q | 显示面板 |
| 保持 Alt，松开 Q 后再次按 Q | 下一个分类 |
| 保持 Alt，Shift+Q | 上一个分类 |
| 保持 Alt，方向键 | 移动选择 |
| 保持 Alt，鼠标在面板内滚动 | 向下下一页，向上上一页 |
| 保持 Alt，PgUp / PgDn | 键盘翻页 |
| 保持 Alt，点击或 Enter | 启动并隐藏 |
| 松开 Alt / 按 Esc / 切换到其他窗口 | 只隐藏 |
| 双击托盘图标 | 打开中文设置 |

长按 Q 不会连续切换分类；启动后需先松开 Alt，才可再次唤起。滚轮只在面板打开、有焦点且鼠标位于面板内时拦截。

自动扫描当前用户和所有用户的开始菜单快捷方式。没有快捷方式的便携软件可在设置中添加。开始菜单不是全磁盘软件清单，部分商店应用不会被枚举。

## 中文设置

右击托盘 → **设置**，或双击托盘图标。

- **软件**：浏览添加程序或 `.lnk`，指定名称及分类；手动配置优先于自动扫描。移除仅修改配置，不删除程序文件。
- **扫描目录**：管理便携软件目录，选择是否递归。建议优先精确添加主程序，避免扫描到辅助程序。
- **分类规则**：输入用 `|` 分隔的关键词，也支持高级正则；上移/下移调整匹配优先级。
- **快捷键与外观**：修改 Alt 配合的触发键、左右 Alt、网格行列数、字号、透明度。
- **分类顺序**：用上移/下移调整面板分类，默认“全部”最后；勾选或取消“显示其他”“显示全部”。隐藏分类不会删除软件数据。

点击 **保存并应用** 会保存、重新扫描并加载配置。**仅保存** 不立即重新加载。保存前验证输入，旧配置备份为 `.ini.bak`；文件被其他编辑器改过时不会直接覆盖。

配置文件是 UTF-8 文本，支持 `%USERPROFILE%` 等环境变量。路径和分类中不要写 `|`。带参数启动应创建 `.lnk` 后添加该快捷方式。

## 配置位置和迁移

| 模式 | 配置位置 |
| --- | --- |
| 安装版 | `%APPDATA%\AltQLauncher\AltQLauncher.ini` |
| 便携版 | EXE 同目录 `AltQLauncher.ini` |
| 直接运行源码 | `.ahk` 同目录 `AltQLauncher.ini` |

日志与配置放在同一目录。日志可能包含本机软件路径，不应上传公共仓库。

**从此前的脚本版迁移**：先退出旧版和新版，将旧的 `AltQLauncher.ini` 复制到新版本对应的配置位置，再启动新版即可，不用重新添加软件。请不要把个人 INI 上传 GitHub。相对路径以程序所在目录为基准，迁移时建议改为绝对路径。

安装/升级/卸载均不会处理旧脚本版的目录，也不会自动覆盖它的个人配置。本仓库只提供干净示例配置。

## 从源码运行

安装 AutoHotkey v2，运行 `src/AltQLauncher.ahk`。首次启动复制旁边的 `AltQLauncher.default.ini` 为个人配置。发行版已经包含运行时，普通使用者不需要安装开发工具。

## 构建

环境：Windows 64 位、PowerShell 7。无需在系统中安装 Ahk2Exe 或 NSIS。

```powershell
pwsh -File ./scripts/build.ps1
```

脚本从官方来源下载固定版本的 AutoHotkey 2.0.31、Ahk2Exe 1.1.37.02a2、NSIS 3.13，核对 `scripts/tools.lock.json` 的 SHA256 后解压到 `.tools/`，运行测试、编译独立 EXE，并制作安装版、便携版和源码包。

结果在 `dist/`；日志、隔离测试文件在 `build/`。源代码保持 UTF-8 无 BOM、LF。可用 `-ToolsPath`、`-BuildPath`、`-DistPath` 指定绝对目录；`-SkipTests` 仅供开发排障，发布前应完整验证。

源码 ZIP 使用 `build.ps1` 中的显式文件清单，新增源码文件后应同步更新清单。每次构建使用全新打包目录，不会沿用上次运行留下的个人配置。

`VERSION` 和 `src/AltQLauncher.ahk` 的 `Ahk2Exe-SetVersion` 应同时更新。打包工具与运行时来源见 [第三方说明](THIRD-PARTY-NOTICES.md)。

## GitHub 发布

1. 将源码 ZIP 解压后的文件放在仓库根目录，包含 `.github/`、`scripts/`、`src/` 等目录；不要再套一层文件夹。
2. 提交源码。`.gitignore` 已忽略个人配置、备份、日志、构建缓存和发行产物。
3. GitHub Actions 会在推送主分支、版本标签、PR 或手动运行时执行构建与测试，在运行页面下载 `AltQLauncher-Windows-x64` artifact。
4. 新建 GitHub Release，上传 `dist/` 中的安装 EXE、便携 ZIP、源码 ZIP 和校验文件。发布二进制时同时提供源码 ZIP，保留第三方授权和对应源码归档。

此工程没有绑定特定 GitHub 用户名或仓库地址，没有自动向任何远程仓库推送或发布。CI 仅使用读取源码和上传本次构建产物所需权限。

## 验证范围

- 核心检查覆盖手动入口优先、快捷方式去重、分类顺序/显隐、设置控件创建、保存校验及空列表。
- `--check` 在指定数据目录中验证真实 GUI 构造，但不显示窗口、不注册全局热键、不启动软件。
- 安装测试使用 `/S /TESTMODE /D=临时目录`，验证文件安装、重复安装保留配置、卸载保留配置。此测试模式不写实际安装注册和快捷方式；正常安装的注册及快捷方式流程经静态检查，未自动操作系统“已安装应用”界面。
- 鼠标硬件、不同输入法、游戏、管理员窗口、远程桌面、混合 DPI 多屏需要实际使用验证。32 位 Windows 和原生 ARM64 未提供构建。

## 排障

- **快捷键无反应**：先松开两侧 Alt，确认托盘已出现；退出占用 Alt+Q 的其他工具，或在设置中修改触发键。
- **管理员窗口前台不响应**：Windows 权限隔离可能限制钩子；先在普通窗口验证。本程序不会自动提权。
- **看不到软件**：确认当前分类，检查原文件是否存在；分类标题中的数字是当前分类数量。修改后要保存并应用。
- **窗口超出屏幕**：减少网格行列数。系统忙碌时隐藏和切换可能受调度影响。
- **升级提示文件占用**：先从托盘退出正在运行的安装版，再重试。
- **恢复默认配置**：退出程序，改名保存个人 INI，再重新启动。不要直接覆盖仍需保留的个人配置。
- **退出**：右击托盘 → 退出。

高级参数：`--settings` 启动后打开设置；`--version` 输出版本；`--check --data-dir 绝对目录` 用于隔离验证；`--library` 仅供测试脚本包含源码。
